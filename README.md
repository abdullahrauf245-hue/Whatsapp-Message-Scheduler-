# 📱 WhatsApp Message Scheduler

A modern, full-stack **WhatsApp Message Scheduler** application featuring a Node.js backend (`Express`, `@whiskeysockets/baileys`, `Socket.io`, `node-cron`, `SQLite`) and a sleek glassmorphism web dashboard UI.

---

## ✨ Features

- 📱 **WhatsApp Web Authentication:** Pair your WhatsApp session instantly via QR Code.
- 📅 **Flexible Message Scheduling:** Schedule one-time or recurring messages (Daily, Weekly, Monthly).
- 🏷️ **Personalization Placeholders:** Dynamic placeholders like `{name}` automatically substituted from contacts database.
- ⚡ **Message Templates:** Save & reuse message templates for quick scheduling.
- 👥 **Contact Management:** Organize contacts with categories and custom tags.
- 📊 **Real-time Monitoring & Logs:** Track pending, delivered, and failed broadcasts in real time with WebSocket updates.
- 🎨 **Modern Dark Glassmorphism UI:** Built with responsive modern design standards.

---

## 🚀 Getting Started

### Prerequisites

Ensure you have **Node.js (v18 or higher)** and **NPM** installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/abdullahrauf245-hue/Whatsapp-Message-Scheduler-.git
   cd Whatsapp-Message-Scheduler-
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the application server:**
   ```bash
   npm start
   ```

4. **Open Dashboard:**
   Open your browser and navigate to:
   ```
   http://localhost:3000
   ```

## 🛠️ Tech Stack

- **Backend:** Node.js, Express, Socket.io, Node-cron, SQLite3
- **WhatsApp Engine:** `@whiskeysockets/baileys`
- **Frontend:** Vanilla HTML5, CSS3 (Glassmorphism & CSS Variables), JavaScript (ES6+), Remix Icon
